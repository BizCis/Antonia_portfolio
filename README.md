# Portafolio web — Antonia Gallegos

Sitio estático basado en el PDF de referencia (`referencia/PORTAFOLIO.pdf`).

**Sitio en GitHub Pages:** https://bizcis.github.io/Antonia_portfolio/

## Vista previa local

```bash
python3 -m http.server 8000
```

Abre http://localhost:8000

## Carpeta de referencia

PDFs de apoyo en `referencia/` (portafolio y CV). El CV publicado en la web es solo el perfil de obra (`assets/cv/`).

## GitHub Pages

El sitio se publica desde la rama `main` (carpeta raíz).
Si aún no está activo: **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
